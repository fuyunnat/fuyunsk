# 项目工作进度面板

工程对话开始/继续并确认项目根时，自动检查面板；“打开进度面板”“可视化 AI 做到哪一步”“切换项目看流程”也读取本规则。面板只显示已记录的进度，不是 AI 内部实时状态，也不冒充已获取应用里的全部聊天。

## 一个数据源

每个实际项目保管自己的 `PROJECT_ROOT/工作流程.md`。同一实际项目的多个对话使用独立任务区块，稳定编号；可选加一行 `对话：修登录 / 调整页面`，不能猜未知对话 ID。不创建第二套任务 JSON、数据库或待办。记录格式、验收与停止仍按 workflow-checklist / bounded-completion，不因面板加新步骤。

面板按任务显示复选框和带 ID/状态的规划表，默认选择最新任务，可切换历史；当前项、下一步、阻塞、状态及清单更新时间直接来自文件。取消不算完成，编号冲突/勾选矛盾提示核实；计数仅代表已记录事项，不代表全项目功能覆盖或测试通过。

AI 实施时沿用短清单：开始标进行中，做完但未验标待验证，真实验收通过才勾选；仅在有进展、阻塞或当前项变化时更新。无需每个工具调用都写文件。用户禁止记录/要求原文恢复时仍按 source-policy 例外，面板不反向添加记录。

## 自动检查与守护

工程对话开始、继续或恢复时，核实当前 PROJECT_ROOT 后运行一次 `--ensure`；已有项目根与用户约束未变，不每次反问。健康面板复用；离线启动本机守护。此默认来自用户明确要求，不要求手写专业提示词。闲聊、概念问答、安装/升级阶段、项目归属未知时不启动；用户要求停用、禁止启动进程或禁止任何写入时服从。普通只读工程任务不写项目清单，面板仍只读已有文件。检查失败简短报告并继续独立业务，不把面板变成新门禁。

```bash
node <技能目录>/scripts/progress-panel-service.js --ensure --project "项目=/已核实的绝对路径"
```

默认从 `http://127.0.0.1:4318` 起选最多 20 个本机端口；复用同项目面板，不关闭占端口的其他服务。显式 `--port 4318` 被占用时报错，不换端口。用返回的真实 URL；不得把远程环境地址说成用户电脑已打开。多项目仍可逐个传 `--project`，只登记明确指定根，不扫描磁盘、全部聊天或导入别的项目。不同根集合不复用同一个守护；需要一个页面看多个项目时一次指定完整集合。

宿主会清理后台进程时，用相同 `--ensure` 命令加 `--foreground`，保留工具返回的执行会话；复用该会话，不每轮开一个。启动输出只证明当次探测，跨命令复查失败不能报持续在线；若宿主两种方式均不支持，报告限制，继续业务，不反复修复或安装系统服务。

守护每秒检查运行状态，面板子进程退出后退避重启，连续 3 次健康失败才处理自己创建的子进程；有限重试：60 秒内 5 次退出停止恢复，下一次工程对话再明确检查结果，不无限补丁。只重启面板，不启动业务服务、数据库或迁移，不安装系统守护、开机启动或部署公网。已有手动启动的健康面板先观察复用，确认端口已释放后再接续启动；不终止旧进程。旧进程失去响应但仍占端口时报告阻塞，不冒充已恢复。

用户说“停止面板”时仅停止当前项目的守护，并遵守其后续停用要求，不立即重启。若返回 panelStillRunning，表示原来的手动面板仍运行，需在原终端停止；不把停止守护说成已关闭旧面板。命令：

```bash
node <技能目录>/scripts/progress-panel-service.js --stop --project "项目=/已核实的绝对路径"
```

脚本仅在操作系统临时目录的当前用户私有子目录保存端口锁、PID、指定根与运行状态，不保存任务、聊天或清单内容，**不是第二套任务状态**。原 `progress-panel.js` 前台 CLI 保留。只需 Node.js 18 及以上标准库，无运行依赖；没有 Node.js 时报告面板不可用，继续业务，不安装无关依赖。

只读取指定根下的工作流程.md，清单不存在显示“尚未建立”，不自动创建；拒绝符号链接，浏览器不能传入任意路径，没有写入 API。禁止访问数据库、.env、上传或其他项目。面板的运行记录不写入业务项目，业务只读边界不变。

## 展示与限制

可切换项目/任务、筛选未完成和阻塞；每 4 秒读取文件，页面隐藏时暂停轮询。AI 未更新清单时，显示最后文件更新时间；连接中断标明旧记录，不伪造实时推进。后续重新启动时用相同的已核实项目路径，进度仍来自同一文件，不需要导入聊天。

宿主是否能展示网页、用户本机是否已启动面板要分别验证。在远程执行环境运行不等于用户电脑已打开；报告真实运行位置、地址及限制。仅看面板不能证明验收完成，也不能保证 AI 每轮遵守记录规则。
